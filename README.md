# Deloitte Data Analytics Virtual Job Simulation

## Overview

This repository contains my completed work from the **Deloitte Data Analytics Virtual Job Simulation** hosted on Forage.

# Task 1: Equality Score Analysis (Excel)

## Business Problem

A client wanted to evaluate salary equality across different job roles using an Equality Score. The objective was to identify roles with fair and unfair compensation patterns.

# Task 2: Machine Telemetry Analysis (Tableau)

## Business Problem

Daikibo collected one month of machine telemetry data from four manufacturing facilities to understand equipment failures.

### Factory Locations

- Meiyo (Tokyo, Japan)
- Seiko (Osaka, Japan)
- Berlin (Germany)
- Shenzhen (China)

Management wanted answers to two questions:

1. Which factory experienced the highest number of machine failures?
2. Which machine types failed most frequently at that factory?


## Task Workflow

- Imported JSON data into Tableau
- Cleaned and organized telemetry records
- Built calculated fields
- Designed interactive dashboards
- Identified factory-level failure trends
- Determined machine types with the highest breakdown frequency
